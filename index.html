Quick reminderYour car has two kinds of pins

IN pins = which way

They only know two words: HIGH and LOW
IN1 → 7IN2 → 8 left wheel
IN3 → 9IN4 → 10 right wheel 
digitalWrite(IN1, HIGH);

EN pins = how fast

A number from 0 (stopped) to 255 (full blast)
ENA → ~5 left wheel speed
ENB → ~6 right wheel speed 
analogWrite(ENA, 150);

Turning is just this: different directions or different speeds on each wheel.

Cheat sheetHIGH + LOW = direction

IN1 (or IN3)IN2 (or IN4)That wheel…
HIGHLOWrolls forward ⬆️
LOWHIGHrolls backward ⬇️
LOWLOWstops (coasts) ✋

Wheel spinning the wrong way? Swap its two wires at the screw terminal. Don't change the code.

ENA & ENBWhat does the speed number mean?

analogWrite(ENA, 150);59% power
🚗

It's a dimmer switch for your motor: the % of time the power is ON.

The big ideaThree ways to turn

Spin

Wheels go opposite ways.
Turns in place, like a top.

Swing

One wheel stops.
Car pivots around it.

Curve

Both forward, different speeds.
Smooth, swoopy arc.

Turn #1Spin right

digitalWrite(IN1, HIGH);  // left wheel
digitalWrite(IN2, LOW);   //   → forward
digitalWrite(IN3, LOW);   // right wheel
digitalWrite(IN4, HIGH);  //   → backward
analogWrite(ENA, 150);
analogWrite(ENB, 150);
delay(400);    // longer = spins farther
Try it
  • Change 400 until it's a perfect 90°.
  • Can you get a full 360°?
  • Flip it to spin left.

Turn #2Swing right

digitalWrite(IN1, HIGH);  // left wheel
digitalWrite(IN2, LOW);   //   → forward
digitalWrite(IN3, LOW);   // right wheel
digitalWrite(IN4, LOW);   //   → STOP
analogWrite(ENA, 150);
analogWrite(ENB, 0);
delay(700);
Try it
  • Spin vs. swing: which needs a longer delay for 90°?
  • Make it swing backward.

Turn #3Curve right

digitalWrite(IN1, HIGH);  // both
digitalWrite(IN2, LOW);   // wheels
digitalWrite(IN3, HIGH);  // go
digitalWrite(IN4, LOW);   // forward
analogWrite(ENA, 200);    // left: fast
analogWrite(ENB, 90);     // right: slow
delay(1500);
Try it
  • Make the gap bigger. Smaller. What changes?
  • Set them equal. Does it really drive straight?
  • Nudge one number until it does.

Pro movesMake your code easy to tweak

  

    


// write a move ONCE…
void spinRight(int spd, int ms) {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  analogWrite(ENA, spd);
  analogWrite(ENB, spd);
  delay(ms);
}

    

    


// …then use it a bunch
void setup() {
  // (pinModes here)
  delay(3000);      // set me down!
  forward(150, 1000);
  spinRight(150, 400);
  forward(150, 1000);
  stopCar();        // or: hallway forever
}
void loop() { }     // empty = run once
